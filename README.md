# RequestSystem

Система учёта заявок. Учебный проект по дисциплине "Технологии разработки программного обеспечения".

## Назначение
Регистрация, обработка и контроль выполнения заявок внутри организации.

## Функции
- Создание заявок
- Назначение исполнителя
- Смена статуса (Новая, В работе, Выполнена, Закрыта)
- Комментарии к заявкам
- Фильтрация и поиск
- Отчёты по категориям и исполнителям

## Стек
Python 3.12, SQLite, Git
