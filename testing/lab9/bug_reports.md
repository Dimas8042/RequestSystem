# Дефекты

## BUG-01 — Несуществующая категория вызывает 500 вместо 400

**Среда:** v1.0.0, локально, http://localhost:8000

**Шаги воспроизведения:**
1. Открыть Swagger UI: http://localhost:8000/docs
2. POST /requests с телом {"title":"Плохая заявка","category_id":999,"author_id":4}
3. Execute.

**Ожидаемый результат:** 400 Bad Request с сообщением "Категория 999 не существует".

**Фактический результат:** 500 Internal Server Error. Сервер падает из-за sqlite3.IntegrityError (FOREIGN KEY constraint failed), ошибка не перехватывается.

**Важность:** высокая.

**Статус:** исправлено.

## BUG-02 — Несуществующий исполнитель вызывает 500 вместо 400

**Среда:** та же.

**Шаги воспроизведения:**
1. PATCH /requests/6 с телом {"assignee_id":999}
2. Execute.

**Ожидаемый результат:** 400 Bad Request с сообщением "Исполнитель 999 не существует".

**Фактический результат:** 500 Internal Server Error (та же причина — IntegrityError).

**Важность:** высокая.

**Статус:** исправлено
