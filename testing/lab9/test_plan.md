# План тестирования RequestSystem v1.0.0

## Объект тестирования
REST API на FastAPI, БД SQLite.

## Среда
- Локальный запуск: http://localhost:8000
- ОС: Windows 10
- Python 3.12
- Инструменты: Swagger UI, curl, DB Browser for SQLite
- Версия коммита: 733674a (develop)

## Что проверяется
- Эндпоинты /requests, /users, /statuses, /categories, /health
- Валидация входных данных
- Коды HTTP
- Целостность данных

## Что НЕ проверяется
- Авторизация (не реализована)
- UI (только API)
- Нагрузочное тестирование

## Виды тестов
Функциональные, негативные, граничные, интеграционные, API.

## Критерий начала
Приложение запущено, БД создана, тестовые данные загружены.

## Критерий завершения
Все 20+ кейсов пройдены, дефекты задокументированы.
