# Автоматические тесты (ЛР №10)

## Установка зависимостей

pip install pytest httpx

## Запуск

Из корня проекта:

pytest testing/lab10/ -v

## Ожидаемый результат

13 passed

## Структура

- test_api.py — 13 тестов
- conftest.py — фикстуры, подготовка БД
- lab10_run.log — лог последнего запуска

## Что проверяется

- Создание заявки (POST)
- Просмотр списка и одной заявки (GET)
- Изменение (PATCH)
- Удаление (DELETE)
- Валидация title (пустая, короткая)
- Регрессия BUG-01 и BUG-02
- Справочники (users, statuses)
- Health-check
